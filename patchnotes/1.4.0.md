**영지전 1.4 — 전장·도박장·보물 창고·무기고**

**새 기능 — 전장(출정)**
• 왕성 외성 장터 반대편에 **출정석**이 생겼습니다. 우클릭 → 초원·설원·황무지(좀비·스켈레톤·피글린) 중 하나를 고르고 [출정]하면 세력원이 60초 안에 [참가]해 같이 떠납니다. 동행 중인 병사만 따라가요
• 적은 참가자 동행 합계의 2배(최대 300)가 본대 → 증원 → 사령관 세 파로 옵니다. 사령관을 잡으면 승리, 보상은 요새와 같고(사령관 보물·경비 주문서) 승리 골드는 참가자가 1/N 씩 나눠 받습니다
• 난이도는 세력장의 요새 난이도 단계 그대로이고, 전장 승리는 난이도를 올리지 않습니다. 세력(무소속은 개인) 쿨다운 30분. 전원 사망은 패배, 퇴각은 보상 없음
• 불사의 깃발·군기·피의 계약·거인의 심장은 전장에서도 그대로 작동합니다

**새 기능 — 도박장**
• 외성 오른편에 **슬롯머신장·경마장·블랙잭장** 세 건물이 생겼습니다. 돈은 내 금고에서 바로 나가고 들어옵니다
• 슬롯: 판돈 1만·5만·10만·50만g, 같은 그림 3개 5~100배, 2개 2배. 모든 판돈의 1% 가 서버 잭팟에 쌓이고 네더의 별 3개면 100배 + 잭팟 전액
• 경마: 말·소·돼지·양·늑대 5마리, 배당 1.5~12배, 마권 1장(1만~100만g) 단승. 마권을 사는 순간 내 경주가 시작되고 바로 정산, 연출은 [건너뛰기] 가능
• 블랙잭: 1만~100만g, 히트·스탠드·더블다운, 딜러 17 스탠드, 블랙잭 2.5배
• 100만g 이상 획득과 잭팟은 서버 방송. 게임별 누적은 영주 탭에서

**새 기능 — 보물 탭**
• 내정 화면에 **보물 탭**이 생겼습니다(영주 탭의 보물 칸은 이리로 옮김). 왼쪽에서 종류를 고르면 보관한 보물이 전부 보이고, 그중 2개까지 [착용]하면 효과가 납니다. 같은 종류는 하나만 착용
• 보물은 실제 아이템 그대로 보관되니 군기를 여러 개 모아 두고 굴림이 좋은 것을 골라 끼거나, [꺼내기]로 꺼내 주문서를 바른 뒤 다시 넣을 수 있어요. 같은 보물이 창고에 있으면 요새에서 또 나오지 않지만 **군기는 또 나옵니다**
• 기존에 끼고 있던 보물은 접속하면 자동으로 보물 탭에 들어가 착용 상태로 이어집니다
• **탭 순서 편집**: 보물 탭 머리줄 [▲▼ 탭 순서]로 자주 쓰는 탭을 위로 올릴 수 있습니다(내 PC 에 저장)

**새 기능 — 무기고 (제작소 Lv2)**
• 제작소 건물 안에 **무기고 상자**가 생깁니다(Lv2 부터). 우클릭하면 장비를 근접 무기·활·석궁·투구·흉갑·각반·부츠 칸에 그대로 보관해요(칸당 Lv2 36개 · Lv3 72개). 주문서 줄 수별로 묶여 보이고 변성·거울·내구도도 표시
• 제작소 안 **서고 상자**를 우클릭하면 서고를 바로 열 수 있고(서고에서 멀어도 됨), **숫돌**도 Lv1 부터 놓입니다. 이미 지은 제작소에도 자동으로 생깁니다

**고친 점**
• 요새 사령관을 잡았는데 보물이 안 보이던 문제(사령관 자리에 떨어져 못 찾던 것)를 고쳤습니다
• 왕실 경매 화면에서 긴 보물 이름이 버튼을 밀어내던 것을 고쳤습니다
• 복위군 공성 때 진지가 땅속·허공에 서던 문제(청크가 안 불려 높이를 잘못 잡음)를 고쳤습니다. 복위군은 도박장 건물과 외성 사이로 돌아옵니다
• 영주 탭에서 보물을 바꿔 끼지 못하던 문제는 보물 탭으로 대체했습니다
• 전장 차원에서는 비가 오지 않습니다
