**⚠ 모드 추가 — 접속 전에 꼭 설치하세요**
• 서버에 가방 모드 **Traveler's Backpack** 이 들어갔습니다. 없으면 접속이 안 됩니다
• CurseForge: 프로필 → **콘텐츠 추가** 에서 **Traveler's Backpack [Fabric]** 과 **Forge Config API Port** 를 설치하세요 (또는 최신 Release 의 curseforge.zip 을 다시 가져오기)
• 레시피를 보고 싶으면 **JEI** 도 같이 (선택, 없어도 접속됨)
• Prism(packwiz) 사용자는 자동으로 받습니다

**새 기능**
• 가방: 제작대에서 가죽 4 + 실 1 + 나무 상자 1 로 기본 가방을 만듭니다. 메고 다니고, 땅에 놓고, 업그레이드할 수 있습니다. 메고 죽으면 죽은 자리에 가방이 놓입니다

**바뀐 점**
• 피글린 석궁병이 2초에 한 발씩 쏩니다 (전엔 1초라 다가가기 어려웠음)
• 병사가 블록에 끼거나 한자리에 몰려도 피해를 입지 않습니다. 끼면 가까운 빈자리로 빠져나옵니다 (부락 정리·대규모 소집 때 죽던 문제)
• 분쇄기는 가방과, 물건이 든 셜커 상자·꾸러미를 갈지 않습니다 (안의 물건이 사라지던 문제)
• 디스코드 #서버공지 의 서버 상태 메시지가 늘 맨 아래에 새로 올라옵니다
